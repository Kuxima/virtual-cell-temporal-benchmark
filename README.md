# Virtual-cell foundation models under temporal extrapolation: a two-embryo benchmark

Clean, reproducible code and artifact release for the manuscript
*"Lineage transfers, identity does not: a cross-species benchmark of virtual-cell
foundation models on temporal extrapolation in embryonic development."*

Seven embedding methods spanning three generations of single-cell representation
learning — PCA-50, Harmony, scVI, STATE SE-600M, UCE (4-layer), Geneformer V1-10M
and TranscriptFormer tf-metazoa — are benchmarked under one frozen, reference-based
kNN protocol (k = 15, cosine, distance-weighted) on two public embryonic atlases
split along developmental time:

| Atlas | Species | Cells | Train | Test |
|---|---|---|---|---|
| Zebrahub | zebrafish | 120,444 | 10–16 hpf (18,109 cells, 16 fish) | 19 hpf–10 dpf (102,335 cells, 24 fish) |
| Mouse gastrulation E-MTAB-6967 | mouse | 108,857 | E6.5–E7.0 (20,308 cells) | E7.25–E8.5 (88,549 cells) |

Headline findings (see the manuscript for full statistics):

- **Coarse lineage identity transfers** across developmental time in every method
  (0.497–0.864 zebrafish; 0.638–0.687 mouse) against 0.352 / 0.266 majority baselines,
  with a decisive, gene-set-controlled zebrafish lead for the natively pretrained
  TranscriptFormer (0.864 [0.839, 0.891]; control 0.869).
- **Fine-grained cluster identity fails in every method and both species**
  (0.040–0.073 vs 0.100 / 0.117 majority) although the same embeddings retrieve it at
  0.63–0.98 in-distribution — the information is represented but not extrapolated.
- **Novel late states are silently absorbed**: correct lineage placement (up to 0.80)
  with near-chance novelty detection (AUROC 0.60–0.66).
- **Random 80/20 splits inflate** shared-cluster accuracy 9–21×, quantifying what
  same-distribution evaluation overstates.
- **Default scArches surgery is a no-op** (bit-identical embeddings despite 41%
  parameters flagged trainable); full unfreezing adds only +4.1 pp lineage accuracy.

## Repository layout

| Path | Contents |
|---|---|
| `src/` | Numbered pipeline scripts: download → preprocess → embed → evaluate → tables → figures (see REPRODUCIBILITY.md for the exact command order) |
| `paper/` | `manuscript.md` (full manuscript), `submission_checklist.md`, `tables/` (Tables 1–2 and Supplementary Tables S1–S9, generated by `src/25_make_tables.py`) |
| `submission/` | Frozen submission package: `figures/` (600 dpi PNG + vector PDF), `tables/`, and the Bioinformatics-format manuscript (`bioinformatics/`) |
| `results/` | Versioned JSON result files backing every reported number, plus generated figures |
| `envs/` | Conda environment snapshots (`biomni_lab`, `fm`, `gears`) with exact `.lock.txt` exports |
| `tests/` | Artifact-schema and evaluation-contract regression tests |
| `provenance/` | SHA256 manifest of all benchmark artifacts with command mapping |
| `data/` | Not committed — see `data/README.md` for atlas and model-weight downloads |

## Getting started

```bash
# 1. environments (names and locks in envs/)
conda env create -f envs/biomni_lab.yml
conda env create -f envs/fm.yml

# 2. data + model weights (place under data/raw/ and models/)
#    see data/README.md

# 3. pipeline order
#    see REPRODUCIBILITY.md — it lists every command in execution order,
#    including the UCE (src/40–45) and TranscriptFormer reimplementation paths

# 4. tables and figures from result JSONs
python src/25_make_tables.py
python src/16_p2_main_figure.py   # + 27 / 29 / 30 / 36 / 22

# 5. contract tests (pytest is not part of the env snapshots; pip install pytest first)
python -m pytest tests -q
```

## Reproducibility guarantees

- Every reported number resolves to a versioned JSON in `results/` and a SHA256 entry
  in `provenance/manifest.json`; nothing is hand-entered into tables. For this public
  release, machine-specific absolute paths in text artifacts were replaced with
  placeholders; the manifest records release-state hashes for shipped files and
  original hashes for the large uncommitted data/model artifacts.
- No fish or embryo contributes cells to both sides of the temporal split; HVGs are
  selected on the training split only.
- The TranscriptFormer inference path is a deterministic reimplementation verified
  against the reference implementation (cosine similarity 1.000000 on probe batches);
  a timed re-run reproduces the mouse embedding bit-identically (max |Δ| = 0).
- Figures use a shared style module (`src/fig_style.py`): Arial, 183 mm double-column,
  bold uppercase panel letters, Okabe–Ito palette.
