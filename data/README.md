# Data and model weights (not committed)

The atlas files (≈27 GB) and model weights (≈18 GB) are not part of this repository.
Recreate the expected layout:

```
data/
  raw/
    zf_atlas_full_v4_release.h5ad      # Zebrahub release v4 (120,444 cells)
    mouse_gastrulation/                # ArrayExpress E-MTAB-6967 raw counts
  processed/                           # generated by src/01*, 06, 12, 17, 20, 40 ...
models/
  run Mouse/                           # STATE SE-600M safetensors checkpoint
  hf_cache/                            # Geneformer V1-10M, TranscriptFormer tf-metazoa
  uce_work/                            # UCE outputs (generated)
external/UCE/                          # git clone of snap-stanford/UCE (MIT)
```

## Atlases

1. **Zebrahub (zebrafish).** Download `zf_atlas_full_v4_release.h5ad` from
   https://zebrahub.sf.czbiohub.org/ . The release is also mirrored on a public
   Google Drive folder; `src/list_zebrahub_drive.py` enumerates it (listing only).
   Citation: Lange et al., *Cell* 2024 (PMID 39454574).
2. **Mouse gastrulation.** Download the raw counts of ArrayExpress accession
   **E-MTAB-6967** from https://www.ebi.ac.uk/arrayexpress/experiments/E-MTAB-6967/ .
   Citation: Pijuan-Sala et al., *Nature* 2019 (PMID 30787436).

## Model weights

| Model | Source |
|---|---|
| STATE SE-600M | https://huggingface.co/arcinstitute/SE-600M (safetensors; `src/07_download_state.py`) |
| TranscriptFormer tf-metazoa | official CZ-Biohub release (fp32 checkpoint 8.6 GB) |
| Geneformer V1-10M | Hugging Face `ctheodoris/Geneformer` (model `gf-6L-30M-i2048` lineage: V1-10M) |
| UCE 4-layer CXG | Hugging Face mirror `lza1/uce_hf` (official figshare is bot-blocked from some networks); model file `4layer_model.torch` plus the per-species protein-token files. Checksums are recorded in `provenance/manifest.json` |

After download, run the pipeline in the order documented in `../REPRODUCIBILITY.md`.
All processed intermediates land under `data/processed/` and are rebuilt from the raw
files by the numbered `src/` scripts; no processed file is required to start.
